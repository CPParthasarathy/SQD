# B4.3 Clean Checkout-to-Flash Reproduction and Cluster B Gate

## Purpose

B4.3 proves that a controlled empty workspace can reproduce the
accepted SQD firmware baseline from an exact Git commit through
toolchain validation, host verification, controlled build, physical
ESP32-S3 erase, flash and bounded serial verification.

B4.3 closes Engineering Foundation Gate G-B. The project may proceed
to C1.1 System Architecture only after this record is Accepted.

## Acceptance criteria

B4.3 is accepted when:

1. Two independent cleanroom passes use separate clone and build paths.
2. Each pass checks out the exact tested commit from the controlled
   repository without reusing an existing clone or build directory.
3. ESP-IDF v6.0.2 is verified at commit
   7101770dc6db2667b3c477cc31365dd1acd6db4e.
4. Python 3.11.15, the ESP32-S3 target and the Heltec WiFi LoRa 32 V3
   compatibility identifier are recorded.
5. B1.3 workstation verification, host tests and the B4.2 contract suite
   pass.
6. The validation or debug profile builds through inherited B3.2
   controls.
7. The physical board is explicitly resolved, erased and flashed.
8. Serial output contains firmware startup, heartbeat and SQD_META
   records with no fatal boot, partition or crash marker.
9. Runtime metadata matches the cloned source commit, build profile,
   ESP-IDF release, target and hardware compatibility.
10. Every authoritative evidence file is covered by SHA256SUMS.txt.
11. Pull-request CI passes.
12. Post-merge main CI passes.
13. The Cluster B gate record is marked Accepted.

## Controlled design boundaries

- CI verifies repository contracts, host tests, clean builds and
  artifact traceability.
- CI does not claim physical erase, flash or serial acceptance.
- Local hardware verification is mandatory for Gate G-B.
- Existing B1.3, B3.2, B3.3, B4.1 and B4.2 controls are reused through
  their accepted interfaces.
- The B3.2 compatibility-branch technique remains isolated inside the
  B4.3 cleanroom and must be removed after each pass.
- The existing active-repository build directory is never reused.

sqd_build_metadata_log() during startup. Debug and validation profiles

verification. Production is not selected for B4.3 metadata capture
because its accepted logging policy suppresses informational records.

## Runtime orchestrator controls

The B4.3 entry point creates a unique cleanroom for each pass, checks out
the exact source commit, activates the accepted B3.2 compatibility branch
inside the disposable clone and invokes the inherited B1.3, B3.2, B3.3,
B4.1 and B4.2 controls. Evidence is staged outside the clone.

A non-destructive plan validation is available through `-PlanOnly`. Physical
erase and flash are rejected unless `-ConfirmHardwareOperations` is supplied.
The serial port is either supplied explicitly or resolved only when exactly
one matching Silicon Labs CP210x interface is present. No COM number is
hard-coded.

Each completed pass produces its own evidence directory, SHA256SUMS.txt and
reproduction manifest. The final command validates the independent-pass
contract through `verify_b4_3.py`.

## First cleanroom execution finding

The first authorized execution stopped during the B4.1 host-test gate,
before build or any board operation. Windows Git checked out
`.clang-format`, `.clang-tidy`, `.editorconfig` and
`tools/ci/requirements-ci.txt` with CRLF because the repository-wide
text rule did not specify a checkout EOL. The active working tree had LF
content, so the defect was visible only in a fresh clone under the host
`core.autocrlf` configuration.

The corrective control changes the repository-wide text attribute to
`* text=auto eol=lf`, while retaining explicit CRLF exceptions for
Windows command scripts and explicit binary classifications. Host
regression tests must clone a fixture with `core.autocrlf=true` and prove
that controlled CI files still contain LF only. No test waiver or
post-clone line-ending rewrite is permitted.

The failed-run evidence is retained externally. No build, hardware
identity, erase, flash or monitor stage was reached.
