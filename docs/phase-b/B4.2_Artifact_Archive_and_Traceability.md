# B4.2 Artifact Archive and Traceability

## Purpose

B4.2 establishes a deterministic firmware artifact archive for every
controlled ESP-IDF build profile and provides cryptographic traceability
from each archived payload to its source, toolchain and CI execution.

## Acceptance criteria

B4.2 is accepted when:

1. The archive contract and finalizer are committed.
2. Debug, validation and production archives contain every mandatory
   application, bootloader, partition, configuration and evidence file.
3. Each archive contains a manifest with source, profile, hardware,
   ESP-IDF and GitHub Actions traceability.
4. Each payload is covered by a SHA-256 inventory and tampering causes
   verification to fail.
5. Missing profile archives fail CI and successful archives are retained
   for 30 days.
6. Local debug, validation and production profile archives pass the
   B4.2 matrix verifier.
7. The pull-request GitHub Actions pipeline passes.
8. The post-merge main GitHub Actions pipeline passes.

## Archive layout

Each controlled profile archive is created under:

- artifacts/b4.2/profile-build/<profile>/

Mandatory archive metadata:

- B4.2_profile_build_provenance.json
- B4.2_artifact_manifest.json
- SHA256SUMS.txt

Mandatory build payloads include the application BIN, ELF and MAP,
bootloader BIN, partition-table BIN, sdkconfig, flasher metadata and
project description. B3.2 profile-build result evidence is retained with
the payload.

## Traceability contract

Each manifest records:

- Source repository and full source commit.
- Build profile and hardware compatibility identifier.
- ESP-IDF release tag and full ESP-IDF commit.
- GitHub workflow, job, run, attempt, event, reference and source SHA
  when the archive is produced in GitHub Actions.
- Relative path, category, byte size and SHA-256 digest for every payload.

## Verification commands

Static repository verification:

```text
python tools/ci/verify_b4_2.py --contract-only
```

Complete local archive-matrix verification:

```text
python tools/ci/verify_b4_2.py \
  --archive-root artifacts/b4.2/profile-build \
  --source-commit <full-source-commit>
```
